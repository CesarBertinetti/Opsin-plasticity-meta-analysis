

This README.md file was created by César Bertinetti on 2025-Jan-23 and is associated with the Bertinetti 2025. Data from: Phenotypic plasticity in visual opsin gene expression: a meta-analysis in teleost fish [Dataset]

The repository contains the datasets and the R Markdown script with step-by-step comments on the different analyses used to generate the results associated with the study:

Bertinetti & Torres-Dowdall 2025. Phenotypic plasticity in visual opsin gene expression: a meta-analysis in teleost fish doi.org/10.5281/zenodo.14776297

DATA & FILE OVERVIEW

1. File List: 

- Opsin_data.csv; Contains the opsin gene expression data from each study, experimental conditions and samples sizes.

- Species_ID.csv; Contains taxon IDs, species name and common names to ensure all taxa are properly incorporated into the phylogenetic tree and match the names in the main datable.

- plast.tre; contains the phylogenetic tree

The "OpsinPlasticity.Rmd" contains the code to replicate the analysis in R Software. Alternatively, a GitHub repository is available at https://github.com/CesarBertinetti/

The analysis was performed running R version 4.4.1 (2024-06-14) on macOS aarch64-apple-darwin20.


A more user-friendly version of the code which allows to preview of the output of single steps is available at https://cesarbertinetti.weebly.com/sharing.html
